개인정보처리방침

탑노트 운영자(이하 “회사”)는 서비스 제공에 필요한 최소한의 개인정보를 처리하고, 통화 음성을 녹음하거나 저장하지 않는 것을 원칙으로 합니다.

1. 처리하는 정보와 목적

정보목적보유
대기 신청 이메일, 활동 지역, 관심 통화, 마케팅 수신 동의 시각·문안 버전베타 초대, 지역별 통화 풀 준비, 동의 증빙초대 종료 또는 수신 동의 철회 시까지
랜딩 세션 임시 식별자, UTM 출처·캠페인·소재, 페이지 경로캠페인별 신청 전환 측정베타 종료 후 지체 없이 집계·삭제
휴대전화번호, Auth 계정 식별자가입, 로그인, 계정 보호탈퇴 시까지
생년월일, 본인인증 성공 여부, HMAC 처리한 DI만 19세 이상·1인 1계정 확인, 재가입 제한탈퇴 시까지. 영구 제한된 계정의 비가역 식별값은 안전 목적상 별도 정책에 따라 보유
가입 자기소개, 대화 목적, 선택 입력한 직업 분야와 추가 인증 희망 항목멤버십 심사와 선택 인증 안내탈퇴 시까지
실시간 카메라로 직접 촬영한 얼굴 사진 3장실제 사람 여부와 프로필 진정성 수동 확인. 미모 점수·광고·상대 공개에 사용하지 않음심사 결과 확정 직후 원본 삭제. 확인 결과·시각·만료만 보유
사용자가 선택 제출한 재직·자격·사업자·학력·소득·자산 증빙선택 인증 배지의 근거 확인. 정확한 회사명·학교명·금액은 상대에게 공개하지 않음심사 결과 확정 직후 원본 삭제. 최소 결과·시각·만료만 보유
닉네임, 지역, 성별 및 상대 성별 선호, 관계 목적, 대화 온도양방향 조건 매칭탈퇴 시까지
인증 종류·상태·확인 및 만료 시각, 검증기관 참조값의 비가역 해시본인·재직·자격 등 선택 인증 결과 표시와 위변조 방지탈퇴 또는 인증 철회·처리 목적 종료 시까지
예약·입장·종료 시각, 매칭·선택·노쇼 기록통화 연결, 다음 통화, 품질·신뢰 점수탈퇴 시까지
신고·차단 내용, 운영자 조치안전 검토, 이용 제한, 분쟁 대응처리 목적과 법적 의무에 필요한 기간
푸시 토큰, 기기 플랫폼, 분석 이벤트통화 알림, 장애 대응, 제품 개선토큰 해지 또는 탈퇴 시까지

2. 수집하지 않거나 공개하지 않는 정보

기본 통화는 녹음하지 않으며 음성 원본을 저장하지 않습니다. 정확한 위치와 연락처 주소록은 수집하지 않습니다. 실시간 얼굴 촬영본과 선택 증빙은 별도 동의 후 비공개 저장소에서 심사할 때만 일시 처리하며 상대에게 공개하지 않습니다. 실명, 전화번호, 정확한 생년월일, 증빙 원본, 정확한 소득·자산액도 상대에게 공개하지 않습니다. 얼굴 촬영본으로 미모 점수나 성별별 차등 심사를 하지 않습니다.

3. 처리위탁과 국외이전

회사는 데이터베이스·로그인(Supabase), 음성 전송(LiveKit), 본인인증(PortOne 및 계약한 본인확인기관), 푸시 알림(Expo/Apple/Google)을 이용할 예정입니다. Supabase 주 데이터베이스는 서울 리전을 선택합니다. 각 업체의 실제 법인명, 이전 국가·항목·일시·방법·보유기간과 거부 방법은 계약 완료 후 이 표에 공개합니다.

4. 삭제와 탈퇴

앱의 나 → 계정과 데이터 삭제에서 언제든 탈퇴할 수 있습니다. 탈퇴 요청이 완료되면 Auth 계정, 프로필, 매칭, 연결, 푸시 토큰을 삭제합니다. 법령상 보관 의무 또는 진행 중인 안전 조사에 꼭 필요한 자료가 있다면 해당 근거와 기간을 별도로 안내하고 분리 보관합니다.

5. 안전조치

전송 구간 암호화, 비공개 증빙 저장소, 사용자·관리자 최소 권한 RLS, 서버 전용 비밀키, 관리자 역할 확인, 심사 감사 로그를 적용합니다. 증빙은 제출자와 권한 있는 심사자만 일시 열람할 수 있고 심사 결과 확정 직후 삭제합니다. 본인확인의 DI 원본은 저장하지 않고 서버 비밀키로 HMAC 처리한 값만 보관합니다.

6. 이용자의 권리

이용자는 개인정보 열람·정정·삭제·처리정지를 요청할 수 있습니다. 앱 안의 설정 또는 고객지원으로 요청하면 본인 확인 후 처리합니다. 베타·마케팅 이메일 하단의 고유 수신 철회 링크를 누르면 대기 신청 이메일과 활동 지역을 즉시 익명화하고 이후 소식을 중단합니다.
