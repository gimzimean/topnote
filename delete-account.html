탑노트 계정 삭제 안내

이 페이지는 탑노트(TopNote) 앱의 계정과 데이터를 삭제하는 방법을 안내합니다.
앱 개발자·운영자: 몬타나 주식회사 (Montana CO.,Ltd) · 문의 support@zzend.app

1. 앱에서 바로 삭제하기

  1. 탑노트 앱을 열고 로그인합니다.
  2. 홈 화면에서 나(설정)로 들어갑니다.
  3. 계정과 데이터 삭제를 누릅니다.
  4. 확인 창에서 계정 삭제를 누르면 즉시 삭제됩니다. 되돌릴 수 없습니다.

2. 앱에 들어갈 수 없다면 — 이메일로 요청하기

앱을 지웠거나 로그인할 수 없다면 support@zzend.app으로 아래 내용을 보내주세요.

  • 제목: [탑노트] 계정 삭제 요청
  • 가입한 휴대전화번호의 끝 4자리와 닉네임
  • 본인 확인을 위해 추가 확인을 요청할 수 있습니다

본인 확인 후 영업일 기준 2일 안에 삭제하고, 완료되면 메일로 알려드립니다. 다른 사람의 계정 삭제는 요청할 수 없습니다.
